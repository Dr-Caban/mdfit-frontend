# Media made for the app (not served by the site)

Kept here for reference. `assets/media` is listed in `.vercelignore`, so none of it is deployed or reachable on
mymdfit.com. The audio the app actually plays is in `assets/tour/` (made by `scripts/tour-voice.js`).

## voice/

Dr. Jared Caban's voice, cloned with his agreement for the first-open tour (ElevenLabs, instant voice clone).

| File | What it is |
|---|---|
| `clone-source/clone-b-source-3min.mp3` | The sample the **live** clone ("Dr.Caban") was made from: three workout videos joined, pauses cut out |
| `clone-source/clone-c-source-natural.mp3` | The sample of the unused clone ("Dr.Caban (natural)"): the same videos with pauses kept |
| `clone-source/workout-video-1.mp3` … `-3.mp3` | The untouched sound of the three workout videos |
| `samples/A-first-recording-multilingual-v2.mp3` | Two tour lines as first recorded (eleven_multilingual_v2): judged too robotic |
| `samples/B-v4-first-clone-LIVE.mp3` | The same lines with eleven_v4 and the live clone: **chosen, live** |
| `samples/C-v4-natural-clone.mp3` | The same lines with eleven_v4 and the natural clone: not used |
| `tour-lines/all-lines-B-v4-LIVE.mp3` | All 18 tour lines as live (voice B, eleven_v4), in order |
| `tour-lines/all-lines-C-v4-natural.mp3` | All 18 lines in voice C, for comparison |
| `tour-lines/first-recording-multilingual-v2.mp3` | The first recording of the original 13 lines |
